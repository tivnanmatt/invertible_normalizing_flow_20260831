# invertible_normalizing_flow_20260831

Invertible normalizing flows for generative image modeling.

## Layout

Executable-paper structure: each pipeline step is one `step<N>_*.py` script at
the repo root, paired with one config in `configs/` and one output folder
under `outputs/` (gitignored, regenerated by running the step). The LaTeX
article in `paper/` includes every step's outputs directly, so `paper/main.pdf`
is an exact record of what was run and what it produced.

```
step1_datasets.py            datasets + dataloaders (also the step-1 test)
step2_tarflow.py             TarFlow training/eval (official apple/ml-tarflow model)
invlib.py                    library of invertible torch modules (2 families)
step3_invertible_modules.py  verification + benchmarks for invlib (24 modules)
step4_tarflow_ablation.py    permutation-slot ablation: what TarFlow autoregresses over
configs/step<N>_*.yml        config per step
outputs/step<N>_*/           data/ (json, csv, tex fragments) + figures/ (png)
paper/main.tex               executable methods & results log -> main.pdf
```

`invlib.py` families: **SeqTransform** — orthogonal maps with TarFlow's
permutation-slot signature (identity/flip/permutations, Haar, Hadamard, DCT,
Hartley, random + learnable Householder/Cayley rotations); orthogonality means
zero logdet and an invariant N(0,I) prior, so they drop into TarFlow and the
model autoregresses over transform coefficients. **InvertibleModule** —
`forward(x)->(y, logdet)` / `inverse(y)`: actnorm, PLU linear, invertible 1x1
conv (Glow), periodic/circular invertible convs in 1D+2D via FFT (Hoogeboom et
al. 2019), monotone cubic (closed-form inverse) and odd polynomials
(SOS-style), invertible leaky ReLU, logit, rational-quadratic splines,
Woodbury low-rank+diagonal, affine coupling, and SpectralFloorLinear (ours:
eigenvalue-floored low-rank map, all unretained eigenvalues set to the
retained floor instead of zero). Step 3 verifies every module (inversion,
autograd-checked logdet, orthogonality, MetaBlock roundtrip) and benchmarks
forward/inverse cost.

Step 2 imports the official TarFlow model (`transformer_flow.py`) unmodified
from a clone of [apple/ml-tarflow](https://github.com/apple/ml-tarflow) at
`/dev_ws/ml-tarflow` (clone it next to this repo; commit is pinned in the
step-2 provenance output). Runs: `mnist_toy` (exact replication of Apple's
train_local.ipynb toy: conditional samples + Bayes classifier eval) and
`cifar10_uniform` (unconditional likelihood, uniform dequantization, official
bits/dim formula).

## Environment

Runs in the `recon-dev` container on axis03 (PyTorch 2.11 + CUDA 12.8 stack):

```bash
docker exec recon-dev python /dev_ws/invertible_normalizing_flow_20260831/step1_datasets.py
```

Datasets live on the axis03 data drive at `/data/image_benchmarks` (mounted
into the container at the same path) — a shared local repository of public
benchmarks. Auto-download: MNIST, FashionMNIST, CIFAR-10/100, SVHN, MedMNIST
2D collection, Imagenette, AFHQ, CelebA (gdrive quota permitting). Manual
(instructions printed and recorded in the outputs when missing): ImageNet,
FFHQ, CelebA-HQ, LSUN bedroom.

Extra packages on top of the container image: `pip install medmnist`,
`apt install texlive-latex-base texlive-latex-recommended texlive-latex-extra
texlive-fonts-recommended` (for the paper).

## Usage

```bash
# run all enabled datasets (downloads on first run)
python step1_datasets.py

# smoke-test a subset
python step1_datasets.py --datasets mnist cifar10

# library use from later steps
from step1_datasets import load_config, build_dataset, get_dataloaders
bundle  = build_dataset("cifar10", load_config())
loaders = get_dataloaders(bundle, load_config())   # {'train','val','test'}
```

Train/val/test policy (seeded, deterministic): official splits used where
they exist (MedMNIST, CelebA); train/test-only datasets get 10% of train
carved off as val; train/val-only datasets (Imagenette, ImageNet, AFHQ) use
official val as test and carve val from train; single-pool datasets (FFHQ,
CelebA-HQ) split 80/10/10.
